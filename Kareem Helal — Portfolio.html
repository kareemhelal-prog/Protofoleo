UNICONNECT — CASE STUDY
THE PROBLEM

University students had no dedicated, closed space for academic collaboration. Course discussions, file sharing and group coordination were scattered across WhatsApp and Facebook — mixed with unrelated noise, hard to search, and open to anyone outside the university.

THE IDEA

Build a private social platform restricted to verified university emails — one space where students and faculty could form groups, share resources, and communicate around actual coursework instead of chat noise.

THE SYSTEM

A role-based platform for Students, Doctors and Admins — subject groups, file sharing, team formation for projects, an academic feed, and real-time messaging built on a follow/following model, so each user's feed reflects who they're actually connected to.

THE ARCHITECTURE

A React front end talking to a Node.js/Express REST API, with MySQL handling users, groups, posts and follow relationships. JWT-based authentication enforces role permissions at the API level. As team lead, I reviewed every pull request — catching bugs and inconsistencies before they reached the main branch.

THE RESULT

Presented to the university and received one of the highest evaluations that year. UniConnect is still running today — live link coming soon.
